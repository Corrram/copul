Community: help, contributing and citation
==========================================

Getting help
------------

Questions are welcome as `GitHub issues <https://github.com/Corrram/copul/issues/new/choose>`_
(use the *Question* template). Please include a short code example. For matters
that should not be discussed publicly, write to the maintainer at
marcus.rockel@finance.uni-freiburg.de.

Reporting bugs
--------------

Use the *Bug report* template on `GitHub <https://github.com/Corrram/copul/issues/new/choose>`_
and include a minimal example, the expected and the actual result, and the
versions of copul, SymPy, NumPy, SciPy and Python. Mathematically wrong results
(an incorrect closed form, a measure outside its range, an invalid copula) are
bugs of the highest priority.

Contributing
------------

Contributions of new copula families, dependence measures, closed-form
formulas, fixes and documentation are welcome. The development setup, the test
commands and the standards for mathematical contributions (references for
closed forms and tests against independent numerical routes) are described in
`CONTRIBUTING.md <https://github.com/Corrram/copul/blob/master/CONTRIBUTING.md>`_.
Everyone interacting in the project is expected to follow the
`Code of Conduct <https://github.com/Corrram/copul/blob/master/CODE_OF_CONDUCT.md>`_.

Changes between versions are listed in the
`changelog <https://github.com/Corrram/copul/blob/master/CHANGELOG.md>`_.

Citing copul
------------

If you use copul in your research, please cite it; citation metadata is
available in `CITATION.cff <https://github.com/Corrram/copul/blob/master/CITATION.cff>`_
(GitHub's *Cite this repository* button). A software paper is in preparation.
