copul.regions package
=====================

Registry of known exact regions between pairs of dependence measures, with
closed-form boundaries, key points, boundary copulas, references and plotting.
See :doc:`research_workflows` for worked examples.

.. automodule:: copul.regions
   :members:

Submodules
----------

The objects above are defined in the following modules; their public members
are documented above.

- ``copul.regions.base`` -- :class:`~copul.regions.ExactRegion` and :class:`~copul.regions.SwappedRegion`
- ``copul.regions.catalog`` -- the registered regions
- ``copul.regions.measures`` -- canonical measure keys and labels
- ``copul.regions.style`` -- plot style used for publication figures
