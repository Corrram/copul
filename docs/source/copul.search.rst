copul.search package
====================

Random checkerboard copulas, counterexample search and stress tests of
conjectured inequalities between dependence measures. See
:doc:`research_workflows` for worked examples.

   :members:

Submodules

are documented above.

- ``copul.search.sampling`` -- :func:`~copul.search.random_checkerboards` and SI rearrangements
- ``copul.search.counterexamples`` -- :func:`~copul.search.check_inequality` and :func:`~copul.search.find_counterexample`
